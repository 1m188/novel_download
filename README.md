# novel_download

最近看道诡异仙的时候，发现有的txt上面有章节内容错误，正确的版本也找不到，找到一个在 [手机电子书](http://www.waptxt.org/) 上正确的版本，但是其官方下载链接却只有前几十章，上网搜了一下各方的小说下载项目发现都不怎么合适，于是索性自己简单实现了一下。使用python3，requests + BeautifulSoup。

## 已实现
1. 从 [手机电子书](http://www.waptxt.org/) 上下载道诡异仙全集到其上更新的最新章节，保存到本地，并做了适当的排版调整，使得其在导入本地微信读书的时候能够有一个不错的排版效果。
2. 从某个章节开始追加。
